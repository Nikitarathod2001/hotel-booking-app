# StayFinder

StayFinder is a MERN stack hotel booking web application where users can search hotels, make bookings, complete secure payments, manage wishlists, and write reviews & ratings.

---

## Features

- JWT Authentication & Authorization
- Hotel Search & Filters
- Wishlist Functionality
- Hotel Booking System
- Stripe Payment Integration
- Reviews & Ratings
- Admin Dashboard
- Cloudinary Image Uploads
- Responsive UI Design

---

## Tech Stack

### Frontend
- React.js
- React Router
- Context API
- Axios
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

### Services
- Stripe Checkout & Webhooks
- Cloudinary

## Installation

### Clone Repository

```bash
git clone https://github.com/Nikitarathod2001/hotel-booking-app
cd hotel-booking-app
```

### Install Dependencies

```bash
# frontend
cd client
npm install

# backend
cd ../server
npm install
```

### Setup Environment Variables

Create `.env` file inside server folder:

```env
PORT=
MONGO_URI=
JWT_SECRET=
STRIPE_SECRET_KEY=
STRIPE_WEBHOOK_SECRET=
CLOUDINARY_CLOUD_NAME=
CLOUDINARY_API_KEY=
CLOUDINARY_API_SECRET=
```

Create `.env` file inside client folder:

```env
VITE_API_BASE_URL=
```

### Run Application

```bash
# frontend
npm run dev

# backend
npm run server
```
